# Carteles de precio

- **Roles:** dueño
- **Tipo:** impresión

## Qué

PDF de carteles grandes o chicos. Plantilla default del sistema, o el dueño sube la suya (grande y chico).

## Criterios de aceptación

- [x] Elegir productos, tamaño grande o chico, generar PDF A4.
- [x] Si no subió nada: plantilla genérica (logo / nombre del local + precio).
- [x] Dueño puede subir imagen plantilla **grande** y **chico** (reemplaza la genérica en ese local).
- [x] Se puede volver a la plantilla genérica.
- [x] Densidad aproximada a la actual: varios por hoja.
- [x] Empleado no entra a carteles (v1).
