# Landing

- **Roles:** visitante (sitio público)
- **Tipo:** UI — página de inicio

## Qué

Página pública para registrarse y ver el producto. La maqueta ya está en `prototipo-web/index.html`. Esta tarjeta la pasa al sitio Angular. No inventar empresa, teléfono ni mail.

## Criterios de aceptación

- [x] Inicio público con el recorrido de la maqueta: carrito, cargar un producto, estadísticas, cargar un empleado y el abono.
- [x] Seis tarjetas: todos los locales desde un solo lugar (cuentas de empleados o socios), un local, estadísticas y cierre de caja, proveedores, modo claro y oscuro, desde el celular.
- [x] Bloque de precio: los primeros 7 días son gratis; si sigue, $ 14.999 por mes por local.
- [x] Abonar desde Mercado Pago, o un link a contacto (ventas).
- [x] Contacto en la misma página. Sin datos inventados.
- [x] Términos y condiciones en el pie.
- [x] Responsive.
- [x] Arranca en modo oscuro y alterna al claro, con transición.
- [x] En Angular: ruta lazy y el CSS del prototipo. `sitemap.xml` incluye el inicio.
