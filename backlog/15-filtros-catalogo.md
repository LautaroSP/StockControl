# Filtros de catálogo

- **Roles:** empleado (lista de caja) · dueño (productos)
- **Tipo:** UX

## Qué

No es una sola lista infinita. Filtrar por sector y agrupar / filtrar por grupo de precio.

## Criterios de aceptación

- [x] Búsqueda por código o nombre (como ahora).
- [x] Filtro tipo: todos / comunes / sector.
- [x] Filtro grupo: un grupo, “sin grupo”, todos.
- [x] Filtro stock bajo (umbral del local).
- [x] Vista dueño: poder **agrupar** la grilla por grupo de precio (expander).
- [x] Los filtros no cambian el stock ni los precios; solo la vista.
- [x] En caja, el empleado usa los mismos filtros de tipo/grupo para encontrar rápido (sin ver costo).
